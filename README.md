# Company Hub

## Запуск

1. Откройте папку проекта.
2. Первый запуск: `npm install`.
3. Далее можно запускать двойным кликом по `Start.bat` или командой `npm start`.
4. Откройте в браузере: http://localhost:3000

## Вход

По умолчанию:
- логин: admin
- пароль: admin

Если в файле `.env` указаны ADMIN_LOGIN / ADMIN_PASSWORD, используются они.

## Обновление через DaData

Создайте файл `.env` рядом с `server.js` и добавьте:

DADATA_TOKEN=ваш_токен
ADMIN_LOGIN=admin
ADMIN_PASSWORD=admin
PORT=3000

После изменения `.env` перезапустите сервер.
